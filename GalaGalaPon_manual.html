1. GalaGalaPon! とは

オリエンテーリング大会のスタートリストを読み込み、同一クラスの中で同じ所属（クラブ・チーム・大学など）の競技者が続けてスタートしている箇所を見つけ、スタート順を入れ替えて解消するツールです。クラス内のスタート順を無作為に決める「抽選」も行えます。

根拠は「日本オリエンテーリング競技規則および関連規則類の運用に関するガイドライン」9.2 スタート順の次の項です。

スタート順抽選の結果、同一クラブ・チームの競技者が連続した場合には、前後の競技者と入れ替えるなどして連続しないようにすることが望ましいが、エントリー時の所属名が統一されていない、または複数のクラブ・チームに所属している競技者がいることにも注意が必要である。

後半の注意点に対応するため、所属名の表記ゆれ（全角半角、大文字小文字、末尾の学年・期、別名）を吸収し、「A/B」のような複数所属も扱います。

特徴内容
ブラウザだけで動くページを開いてファイルをドロップするだけ。インストール不要。PC のブラウザ（Chrome、Edge、Safari など）で使えます
データは送信しない読み込んだスタートリストはブラウザの中だけで処理され、サーバーには一切送られません（アクセス解析で送るのはページの閲覧と、実行ボタンを押した回数・大会名・人数だけです）
再現できる並べ替えは「seed（乱数の種）」の番号で決まり、同じ番号なら何度やっても同じ結果になります。承認や記録に使えます
JOY・Mulka2 に対応Japan-O-entrY のエントリーリストを読み、Mulka2 取り込み用の Startlist.csv を出力できます

2. 使う前に

2.1 読み込めるファイル

形式内容判定
JOY のエントリーリスト（CSV）Japan-O-entrY からダウンロードした NNNN_entrylist*.csv。1行目が「申込代表者…」、2行目が「申込ID…」の2段見出し。読み込む列はクラス・氏名1・氏名2・所属・申込ID・その他連絡事項・カード番号・登録番号。1レコードに複数人（リレー）がいれば人ごとに分けますファイル名または見出しで自動判定
Mulka2 取り込み用スタートリスト（CSV）Startlist.csv。1行目が「クラス,スタートナンバー,氏名１,氏名2,所属,スタート時刻,カード番号,カード備考,競技者登録番号」。JOY2Mulka や Start Designer の出力、または Mulka2 向けに手で作ったもの見出しで自動判定
一般の CSVクラス・氏名・所属・スタート時刻の列があるもの。列の対応を画面で指定します（見出しから自動推定）列の対応画面が出ます
スタートリスト HTMLDATA を埋め込んだ形式のスタートリスト HTML（作者の大会で使っている形式）自動判定

文字コードは UTF-8（BOM の有無を問わず）、Shift_JIS、UTF-16（Excel の「Unicode テキスト」）に対応し、区切りはカンマ・タブを自動判定します。

2.2 スタート時刻の有無

スタート時刻が入っているリスト（Mulka2 形式など）では、クラスごとの時刻の集合を「枠」として、人と枠の対応だけを入れ替えます。時刻が入っていないリスト（JOY のエントリーリストなど）では、ファイル内の並び順をスタート順の枠とみなします。どちらの場合も、クラスをまたいで人が動くことはありません。

3. 画面の構成

部位内容
ヘッダーロゴと説明文。「データはどこにも送信しません」の方針もここに書いてあります
ファイル読み込み点線の枠にファイルをドロップするか、クリックして選択。読み込み結果（ファイル名・人数・形式）がその下に出ます
操作パネル大会名、seed、抽選のチェック、「チェック」「並べ替え」「検証」「別案（次の seed）」「前の案に戻る」「元の並びに戻す」、ダウンロードの各ボタン、印刷
判定の設定（折りたたみ）所属として扱わない語、同一視する所属、所属辞書のオン／オフ。詳細は6章
ステータス行人数・連続ペア数・該当者数、並べ替え後は seed と結果。その下に「所属統一：n パターン／m 名」と、seed ごとの履歴表・残った連続ペアの一覧
スタートリストクラスごとにまとめた表。列は 順・スタート・氏名・所属・No・SEQ（・レーン・連絡事項）。男子クラスは水色、女子クラスはマゼンタ、その他はグレーの見出し

4. 基本の流れ

  1. 読み込む。 ファイルをドロップします。読み込みと同時に「チェック」が走り、同一所属が連続している箇所が赤字になります。一般の CSV では列の対応を確認して「この対応で読み込む」を押します。
  2. 大会名を確かめる。 ファイル名やタイトルから自動で入ります。変更一覧 CSV や作者への連絡に使うので、必要なら直します。
  3. 抽選するかを決める。 「クラス内のスタート順を抽選する」は既定でオンです。JOY のエントリーリストのように、まだスタート順が決まっていないリストではオンのまま、Mulka2 や Start Designer ですでに抽選・配置済みのリストを調整だけしたいときはオフにします。
  4. 並べ替える。 「並べ替え」を押すと、（抽選オンなら各クラスを無作為に並べ替えたうえで）同一所属の連続を解消する入れ替えを行います。1秒かかりません。ステータス行に「seed 1（抽選あり）：連続ペア 11 組 → 0 組／時刻変更 43 名／全 52 名」のように結果が出ます。
  5. 別の案を見る。 「別案（次の seed）」で seed を1つ進めた別の並びが出ます。履歴表に seed ごとの連続数・変更人数が並び、クリックで切り替えられます。「前の案に戻る」「元の並びに戻す」もあります。
  6. 検証する。 「検証」を押すと、読み込んだ全員が同じクラスで出力に載っているか、クラスごとのスタート枠が入力と一致しているかを確かめ、クラスごとに OK（青）／NG（赤）を表示します。
  7. ダウンロードする。 並べ替え後リスト CSV（JOY・Mulka2 形式入力時は Startlist.csv）、変更一覧 CSV、結果 HTML（HTML 入力時のみ）を保存します。印刷もできます。

5. 表示の見方

表示意味
赤字・太字の行前または後ろの人と同一所属と判定された競技者。所属欄の右に赤で「◀ 共通の所属」が付きます
青字の時刻「10:01 (旧 9:55)」並べ替えで時刻が変わった競技者。カッコ内が元の時刻。時刻のないリストでは、SEQ の数字が青になります
緑の「▶ 正表記」所属辞書によって表記が統一される所属。画面は元の表記のままで、ダウンロードするファイルでは正表記に置き換わります
順クラス内の並び順（1 から）
Noスタートナンバーまたは申込ID（入力の値）
SEQ入力ファイルの何番目のレコードか（1 から）。並べ替えても変わらないので、「元は何行目の人か」を辿れます
連絡事項JOY の「その他連絡事項」。出走時刻の希望などを見ながら調整できます
所属統一：n パターン／m 名辞書で表記が変わる組の種類数と人数
残った連続ペア並べ替え後も解消できなかった組。2名だけのクラスで両者が同一所属の場合など

6. 設定

6.1 seed と抽選

項目内容
seed（並べ替えに使う乱数の種）並べ替えに使う乱数の出発点となる番号。同じ入力・同じ設定・同じ seed なら必ず同じ結果になります。別の並びがほしいときは番号を変えます。確定した seed は変更一覧 CSV の先頭行に記録されます
クラス内のスタート順を抽選するオン（既定）：各クラスの全員を seed 固定の乱数で無作為に並べ替えてから、同一所属の調整をします。オフ：入力の並びを出発点に、最小限の入れ替えだけで連続を解消します。抽選済みのリストを調整するだけのときはオフにしてください

6.2 判定の設定（折りたたみを開く）

項目内容
所属として扱わない語（1行1語）「オフィシャル」「コーチ」「試走」のように所属欄に書かれることがあるが所属ではない語。ここにある語は判定で無視されます。既定の一覧が入っており、足し引きできます
同一視する所属（1行に「正表記=別表記=…」）整形では同じにならない言い換えを同一視します。先頭が正表記で、出力ファイルの所属はこれに置き換わります（例 ES関東C=ES関東クラブ）。既定で所属辞書の別名が入っています。「既定に戻す」で戻せます。編集内容は再読み込みで消えますが、「編集内容をこの端末に記憶する」にチェックするとそのブラウザに保持されます
所属辞書で表記ゆれを名寄せするオン（既定）：全日本規模の実績データ（2025年4月以後、約3,300の所属）から作った辞書で、所属を多数派の表記に統一して判定・出力します。オフ：入力の表記だけで判定し、出力も置換しません
この同一視設定を作者に送る同一視欄を既定から変えた差分を、作者の Google フォームに入れた状態で開きます。送信はフォーム上で行うので、押しただけでは何も送られません。11章

7. 出力ファイル

ファイル内容
Startlist.csv（JOY・Mulka2 形式入力時）Mulka2 取り込み用の9列：クラス、スタートナンバー、氏名１、氏名2、所属、スタート時刻、カード番号、カード備考、競技者登録番号。BOM付き UTF-8、クラス順→並べ替え後の順。JOY 入力ではスタートナンバーにクラス内連番を自動付与し、スタート時刻・カード備考は空欄。Mulka2 形式入力では元の列と内容を保ち、スタート時刻と所属だけ更新
並べ替え後リスト CSV（一般 CSV・HTML 入力時）一般 CSV では元の列構成のまま、スタート時刻と所属を更新。HTML では No・クラス・レーン・スタート・氏名・所属・ふりがな・カード番号・カード備考・バス
変更一覧 CSV先頭行に大会名・seed・抽選の有無・連続ペア数（前→後）・変更人数を記録し、以下にクラス・No・氏名・所属・旧スタート・新スタート（時刻のないリストでは「n番目」）。イベントアドバイザーへの説明資料に使えます
結果 HTML（HTML 入力時）元のスタートリスト HTML に、赤字（連続）・青字（時刻変更）・緑の「▶ 元 …」（所属の置換元）を実テキストで加えたもの。ブラウザで検索できます

所属の置換は、辞書のチェックがオンのときだけ行われます。末尾の学年・期・卒業年などの数字（青葉会22、筑波大学 2、東大OLK41期）は、判定では無視しますが、出力では元のまま残します。

8. 判定のルール

8.1 所属の整形（判定用のキーを作る）

#処理例
1スラッシュ（/ ／）で分割し、要素ごとに扱う桐嶺会/練馬OLC → 桐嶺会、練馬OLC
2半角を全角に、英字を大文字にそろえる千葉大olc → 千葉大ＯＬＣ
3末尾の n期・n年・数字（直前の空白も）を落とす青葉会22 → 青葉会、筑波大学 2 → 筑波大学
4数字始まり、都道府県名n、都道府県名-n走、「-」のみ、カッコや●？を含むもの、空欄は所属として扱わない3年、愛知２、神奈川-1走、(無所属)
5「所属として扱わない語」を除くオフィシャル、コーチ
6「同一視する所属」と所属辞書で正表記のキーに寄せるES関東クラブ → ES関東C、入間OLC → 入間市OLC

8.2 連続の判定

各競技者を「所属キーの集合」として持ち、クラス内をスタート順に並べ、隣り合う2人の集合に共通のキーがあれば「同一所属の連続」とします。複数所属の人は、どの要素で重なっても該当します。所属が空欄の人や、整形の結果キーが一つも残らない人は、誰とも連続しません。

8.3 並べ替え

クラスごとのスタート枠（時刻の集合、または並び順）は変えず、人と枠の対応だけを入れ替えます。目的は「連続ペア数を最小に、同点なら動かす人数を最小に」です。手順は、衝突している人を衝突が減る相手と入れ替える貪欲修復、残った衝突を焼きなまし法で解消、衝突を増やさない範囲で元の枠に戻す、の3段階で、乱数は seed で固定されています。抽選オンのときは、この前にクラス内を無作為に並べ替えます。

9. 運用のヒント

場面ヒント
JOY から Mulka2 へJOY のエントリーリストをドロップ → 抽選オンで並べ替え → 検証 → Startlist.csv を保存 → Mulka2 のイベントマネージャに取り込み。スタート時刻は Mulka2 側（または Start Designer 側）で付けます
Start Designer と組み合わせる枠（レーン・時刻・間隔）の設計は Start Designer、人の配置と所属の調整は GalaGalaPon! という分担になります。Start Designer のスタートスロット一覧に人を流し込んだ Startlist.csv を作ってから、抽選オフで読み込んで調整します
イベントアドバイザーの承認ガイドラインではスタート順の決定方法に承認が必要です。変更一覧 CSV（seed・抽選の有無・変更内容）と検証結果を添えると説明しやすくなります
連絡事項への対応「出走時刻をずらしてほしい」などの要望は連絡事項列に出ます。該当者を手で入れ替える場合は、出力した CSV を直してから、もう一度読み込んで（抽選オフで）チェックすると、連続が増えていないか確かめられます
解消できない組が残ったとき2名だけのクラスで両者が同一所属、複数所属の人が多いクラスなどでは、残ることがあります。赤字の箇所を見て、手で入れ替えるか、クラス間のスタート間隔で対処します
自クラブ特有の表記「寿会=寿會=早大OC OB会」のような言い換えは、同一視欄に1行足せばその場で効きます。ほかの大会でも役立ちそうなら、作者に送ってください

10. 困ったときは

症状対処
ファイルを読み込んでも「DATA が見つかりません」「列が見つかりません」と出る形式が想定と違います。JOY は2行目に「申込ID」「クラス」「氏名1」「所属」があるか、Mulka2 形式は1行目に「スタートナンバー」があるかを確認してください。一般の CSV なら列の対応画面で指定できます
文字化けするUTF-8／Shift_JIS／UTF-16 は自動判定しますが、まれに外れます。Excel で「CSV UTF-8（コンマ区切り）」として保存し直してください
並べ替えても並びが変わらない連続がもともと無いか、抽選がオフで最小限の入れ替えで済んでいます。ステータス行の数字を確認してください
同一所属なのに赤くならない表記が整形で同じにならない言い換えです。同一視欄に「正表記=別表記」を足してください。所属欄が空欄の人は判定されません（ステータス行に人数が出ます）
別の所属なのに赤くなる辞書や同一視で寄せすぎています。同一視欄の該当行を消すか、辞書のチェックを外してください
「検証」が NG になる通常は起きません。もし出たら、表に出た理由（出力にいない／入力にいない／スタート枠が一致しない）とファイルを作者に知らせてください
設定を変えたのに反映されない設定を変えたら「チェック」または「並べ替え」を押し直してください

11. 作者への連絡

同一視の設定を見直した場合は、設定欄の「この同一視設定を作者に送る」で、既定との差分（足した行・消した行）と大会名を入れた Google フォームが開きます。内容を確かめて「送信」してください。お名前・連絡先は任意です。不具合や要望も同じフォームの「辞書変更内容」欄にお書きください。寄せられた言い換えは、確認のうえ次の版の辞書に反映します。

GalaGalaPon! は無償で提供しています。利用による結果については利用者の責任で確認してください。アクセス解析（Google Analytics）はページの閲覧と、実行ボタンの回数・大会名・人数のみを記録し、選手名や所属などのデータは一切送りません。
